# বর্তমান ভাঙা অংশ ঠিক করার পরিকল্পনা

## যা ঠিক করব
- রিপোর্ট করা `utils.ts` টাইপ ত্রুটিটি বর্তমান কোডে সত্যিই আছে কি না টাইপ চেক দিয়ে নিশ্চিত করব।
- প্রথমবার পেজ খোলার সময় Google Translate মূল HTML বদলে দেওয়ায় যে hydration error হচ্ছে, সেটি সরাব।
- অনুবাদ সুবিধাটি পেজ পুরো চালু হওয়ার পর লোড করব, যাতে ফিচারটি থাকে কিন্তু পেজ ভাঙে না।
- বর্তমান বিল্ড, ব্রাউজার কনসোল এবং গুরুত্বপূর্ণ পেজ পুনরায় পরীক্ষা করব।

## কারিগরি বিবরণ
- `utils.ts` বর্তমানে ৬ লাইনের; তাই `8:7` বার্তাটি পুরনো বিল্ডের কিনা যাচাই হবে।
- Translate script আর server-rendered head-এ আগেভাগে চলবে না; browser hydration শেষ হওয়ার পর একবার যোগ হবে।
- টাইপ চেক, preview build signal এবং Playwright browser test দিয়ে ফল যাচাই হবে।
